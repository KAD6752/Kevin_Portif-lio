# Contato - Amigos da Fé

`contact.html` funciona como página de contato e pré-agendamento para a barbearia Amigos da Fé.

## Objetivos da página

- Permitir contato rápido por WhatsApp, e-mail e Instagram.
- Coletar leads com nome, telefone, origem, serviço desejado e observação.
- Destacar horários comerciais e oferta de planos mensais.
- Direcionar o visitante de volta para a home e para o dashboard demonstrativo.

## Observação

Os formulários usam `mailto:` por se tratar de um site estático. Em uma versão com backend, os dados devem ser enviados para um CRM, banco de dados ou API de agenda.
