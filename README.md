Projetos, estudos e evolução em desenvolvimento web.

## Projeto em destaque: O AURA Visage Spa

Site comercial para estética, beleza e bem-estar, com identidade visual, catálogo de serviços e encaminhamento para agendamento. Projeto conduzido por Kevin Dias com desenvolvimento assistido por IA e validação do responsável junto à equipe do AURA.

**[Ver site publicado](https://aura-visage-spa-preview.kdias6752.chatgpt.site)** · **[Código e apresentação](projetos/aura-visage/README.md)**

- [Estudo de caso: problema, decisões e resultado entregue](projetos/aura-visage/docs/01-estudo-de-caso.md)
- [Guia de código: HTML, CSS, JavaScript e sintaxe](projetos/aura-visage/docs/02-guia-de-codigo.md)
- [Como apresentar e comercializar a entrega](projetos/aura-visage/docs/03-como-apresentar-e-vender.md)
- [Execução local e manutenção](projetos/aura-visage/docs/04-operacao-e-manutencao.md)

A implementação usa módulos nativos e scripts Node.js sem dependências de produção. As reservas acontecem no Trinks; a recepção atende pelo WhatsApp. Não há API de sincronização, chatbot ou resultados comerciais mensurados anunciados como concluídos.

## Organização

A página pessoal existente permanece na raiz. O código completo e os materiais do AURA ficam em `projetos/aura-visage/`. Para executar, entre nessa pasta e siga o README do projeto. A demonstração do produto está hospedada no Sites, separadamente do repositório.

Marcas e imagens de cada projeto pertencem aos respectivos titulares. A publicação como portfólio não concede licença de uso desses materiais em outros negócios.
